Nút bấm & phân trang

Ví dụ sống dùng cùng buttons.css và pagination.css với cửa hàng. Nút mẫu chỉ thể hiện trạng thái; liên kết mở trang HTML thật.

1. Nút bấm2. CSS và box model3. Phân trang4. Phân biệt trạng thái5. Thực hành

1. Nút bấm và liên kết

Di chuột để xem :hover, nhấn giữ để xem :active, dùng Tab để xem :focus-visible. Nút bị vô hiệu hóa được bỏ qua trong thứ tự Tab.

Xem sản phẩm 
<button class="btn btn-buy" type="button">Mua ngay — minh họa</button>
<button class="btn btn-buy" type="button" disabled>Mua ngay — vô hiệu hóa</button>
<a class="btn btn-outline" href="./products/index.html">Xem sản phẩm</a>

type="button" tránh gửi form ngoài ý muốn. disabled là thuộc tính HTML của nút; CSS chỉ định dạng cách hiển thị.

2. CSS và box model

padding tạo khoảng trống trong nút; border tạo viền; border-radius bo góc. cursor đổi con trỏ, không thêm hành vi mua hàng. Kích thước và màu là giá trị đã áp dụng trong cửa hàng.

Mở file buttons.css

/* P06 — Nút bấm: HTML xác định hành động, CSS định dạng và phản hồi.
   <a class="btn"> dùng để đi tới trang khác; <button> dùng cho nút mẫu.
   :active là lúc nhấn, khác với class .active của thanh phân trang. */
.btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: 8px;
  min-height: 44px;
  padding: 12px 20px;
  border: 1px solid var(--border);
  border-radius: 8px;
  background-color: var(--card);
  color: var(--foreground);
  font: inherit;
  font-size: 14px;
  font-weight: 600;
  line-height: 1.4;
  text-align: center;
  text-decoration: none;
  cursor: pointer;
  transition:
    background-color 0.2s,
    border-color 0.2s,
    color 0.2s,
    transform 0.2s;
}
.btn-primary,
.btn-buy {
  background-color: #c92525;
  border-color: #c92525;
  color: white;
}
.btn-outline {
  background-color: transparent;
  border-color: #c92525;
  color: #a91f1f;
}
/* Hover chỉ áp dụng khi nút còn khả dụng. */
.btn:hover:not(:disabled) {
  background-color: var(--secondary);
  border-color: #c92525;
  transform: translateY(-2px);
}
.btn-primary:hover:not(:disabled),
.btn-buy:hover:not(:disabled) {
  background-color: #a91f1f;
  color: white;
}
.btn:active:not(:disabled) {
  transform: translateY(1px);
}
/* Giữ focus nhìn thấy khi sử dụng bàn phím hoặc điều hướng hỗ trợ. */
.btn:focus {
  outline: 2px solid #a91f1f;
  outline-offset: 3px;
}
.btn:focus-visible {
  outline-width: 3px;
}
.btn:disabled {
  opacity: 0.5;
  cursor: not-allowed;
  transform: none;
}
@media (prefers-reduced-motion: reduce) {
  .btn {
    transition: none;
  }
  .btn:hover:not(:disabled),
  .btn:active:not(:disabled) {
    transform: none;
  }
}

4. Phân biệt trạng thái

.active
Class được viết sẵn trên li của trang hiện tại; đi cùng aria-current="page" trên liên kết.
:active
Pseudo-class trong lúc người dùng kích hoạt phần tử, chẳng hạn nhấn giữ nút chuột.
:disabled
Khớp nút hoặc control HTML thật sự bị vô hiệu hóa. Thẻ a không hỗ trợ thuộc tính disabled.
.disabled span
Ở giới hạn đầu/cuối, thay liên kết bằng span không có href. aria-disabled mô tả trạng thái; nó không tự chặn tương tác.

5. Luồng thực hành không cần JavaScript

  1. Dùng Tab tới nút mẫu, quan sát viền focus và nút disabled bị bỏ qua.
  2. Mở ba khối HTML phân trang; tìm vị trí class active và span disabled.
  3. Đi từ trang 1 đến trang 3, mở một sản phẩm rồi dùng liên kết quay lại danh sách.
  4. Thu nhỏ cửa sổ hoặc phóng to 200%; kiểm tra văn bản, nút và phân trang.
  5. Mở file CSS, đổi một màu hoặc padding, lưu và tải lại trang.
